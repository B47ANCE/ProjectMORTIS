# Project M.O.R.T.I.S. Master Roadmap

Canonical version: 0.23.3-dev.1; public API 1.5.0.

Authority/replication source corrections are recorded in [AUTHORITY_REPLICATION.md](AUTHORITY_REPLICATION.md); native verification remains open. Food-provider transactions and full locomotion baseline restoration remain explicit follow-ups.

## Implemented

- Versioned identity, component persistence/replication, capability negotiation,
  diagnostics, bounded schedulers, location memory, and logical groups.
- Species hierarchy, infected signals, command hierarchy, hunger/starvation,
  collision/crowd flow, trips, piles, movement ceilings, and trauma transitions.
- Canonical anatomy/tissue, clothing transmission, severing, attachments,
  detached material conservation, corpse/death provenance, wound promotion,
  systemic consequences, and decomposition/desiccation infrastructure.
- Research archive content integration and provider-oriented API boundaries.
- EXT-32 support through a bounded, explicit corpse/death-provenance evidence
  provider consumed by experienceWorks history authority; no automatic memorial
  creation or presentation ownership.
- Removed the revoked EXT-29 NPC-framework registry, concrete Project Remnants
  adapter, public entry points, positive test, and compatibility documentation.

## Still to add

- Expand APIs/weapon providers only for concrete approved consumers.
- Refine anatomy, trauma, locomotion, crowd flow, feeding, and desiccation from
  runtime evidence.
- One medWorks left-hand native render experiment before broader dismemberment.
- Dependent-character capability only after an approved content owner supplies
  concrete identity/lifecycle/action requirements.
- Add an approved history-content/presentation producer before treating EXT-32
  as player-facing; MORTIS supplies evidence only.

## Validation and release gates

- Native wounds, clothing, sever state, attachments, death/corpse lifecycle,
  hunger migrations, research items, trips/piles, population tuning, logical
  groups, memory, save/load, streaming, late join, hosted, and dedicated servers.
- Validate explicit history evidence against native corpse identity across
  carry/drop, save/reload, reanimation, late join, and concurrent requests.

## Prohibited

- Project Remnants support, detection, adapters, patches, or generic integration.
